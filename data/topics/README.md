# Banco de temas v1

`topics_v1.yaml` contiene 36 preguntas sintéticas, una taxonomía compartida por
intereses y temas, y pares simétricos de categorías relacionadas. `LOW` y `MEDIUM`
son niveles operacionales iniciales, no una medida empírica de polarización.

Un interés puede ser una categoría o subcategoría. Un tema obtiene puntuación 1.0
si coincide con la categoría o subcategoría del estudiante, 0.5 si corresponde
a una categoría relacionada, y 0.0 en otro caso. Cambios en categorías, pares o
preguntas requieren una nueva versión del banco para preservar reproducibilidad.
